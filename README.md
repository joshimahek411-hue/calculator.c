Simple Calculator in C
📌 About the Project

This is a simple calculator program written in the C programming language.

It allows users to perform basic mathematical operations such as addition, subtraction, multiplication, division, and remainder.

The program uses functions and a menu-driven approach to perform calculations based on the user's choice.

This project is suitable for beginners who are learning the fundamentals of C programming.

✨ Features
Addition of two numbers
Subtraction of two numbers
Multiplication of two numbers
Division of two numbers
Remainder calculation
Menu-driven interface
Checks for division by zero
Repeats the menu until the user chooses to exit
🛠️ Technologies Used
Programming Language: C
Header File: stdio.h
Input Function: scanf()
Output Function: printf()
Control Statements: switch, if-else, and do-while
User-Defined Functions: Separate functions for each arithmetic operation

🚀 How to Run the Project
Step 1: Clone the Repository
git clone <your-repository-url>

Step 2: Open the Project Folder
cd simple-calculator

Step 3: Compile the Program

If GCC is installed, run:

gcc calculator.c -o calculator

Step 4: Run the Program

On Linux or macOS:

./calculator


On Windows:

calculator.exe

⚠️ Limitations
The calculator works with integer values only.
Decimal results are not supported.
The program does not currently validate invalid keyboard input.
Integer overflow is not handled.
